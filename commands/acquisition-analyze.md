# AI集客分析

ユーザーから商品・サービスURLを受け取ったら、AI Acquisition Search の MCP ツール `analyze-acquisition` を使用する。

## 実行

1. URLが指定されていない場合は、分析したい商品・サービスURLを1つだけ確認する。
2. `analyze-acquisition` にURLを渡す。
3. 返ってきた分析結果を、以下の順で日本語で整理する。
   - 商品分析
   - 市場分析
   - 顧客分析
   - 競合分析
   - 実績分析
   - 集客課題
   - 集客機会
   - 優先順位
   - 次にやるべき集客アクション
4. ページから確認できた事実とAIによる仮説を混同しない。
5. 情報不足の場合は推測で埋めず、「情報不足」と明示する。
